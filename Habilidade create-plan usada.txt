Resposta Técnica: Gravação Simultânea Frontal + Traseira no Snapdragon 439
Preciso ser direto sobre uma limitação de hardware crítica que impacta o escopo do projeto:

❌ Gravação simultânea dual camera NÃO é viável neste dispositivo
O Snapdragon 439 possui um único ISP (Image Signal Processor) — o Qualcomm Spectra 150. Ele é fisicamente incapaz de processar dois pipelines de câmera independentes ao mesmo tempo para codificação de vídeo. Isso não é uma limitação de software — é uma restrição de silicon.

O que acontece se tentar:

O Camera2 API / CameraX lançará CameraAccessException ao tentar abrir a segunda câmera enquanto a primeira está gravando
Mesmo que não lance exceção imediatamente, o driver multiplexará o ISP resultando em: dropped frames severos, superaquecimento acelerado, possível crash do serviço de câmera do sistema
Evidência concreta: O CameraX ConcurrentCamera API (introduzida no CameraX 1.3) exige que o dispositivo declare suporte a StreamConfigurationMap para câmeras concorrentes via CameraManager.getCameraCharacteristics. O Redmi 8A com Snapdragon 439 não declara esse suporte.
